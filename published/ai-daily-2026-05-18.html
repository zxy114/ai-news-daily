RecursiveMAS 框架提速多 Agent 推理：2.4x 速度提升 + 75% token 节省

核心事件：UIUC 和斯坦福联合提出 RecursiveMAS 框架，让 AI Agents 之间共享 embeddings 而不是文本，大幅降低 token 消耗和训练成本。

关键数据：多 Agent 推理提速 2.4 倍，token 使用减少 75%，训练成本降低超过一半。

影响范围：所有多 Agent 系统（协作 Agent、Multi-Agent 框架、Agent orchestration 系统）。

后续动作：开源代码已发布，可集成到现有 Agent 系统中。

解读分析：Token 成本是 Agent 商业化的最大障碍。RecursiveMAS 从根本上解决了这个问题——用 embedding 共享代替文本通信，这可能是多 Agent 技术能否商业化落地的关键拐点。

关键数据：系统采用 "监督-执行" 双 Agent 架构，监督 Agent 每 5 分钟评估执行 Agent 的错误率，自动触发重训练。
