🏆 Cerebras 天量 IPO：募资 $55 亿，首日暴涨 108%，估值 $660 亿
📅 发布日期：2026-05-14 📰 TechCrunch BREAKING
📌 核心事件
AI 芯片公司 Cerebras Systems 周四完成 IPO，发行价 $185（远超原区间 $115-$125），募资 $55 亿。开盘价 $385，暴涨 108%，收于 $311，市值达 $660 亿，成为 2026 年首个科技巨头级 IPO。
📊 关键数据
2025 年营收 $5.1 亿（同比+76%），净利润 $2.378 亿（前一年亏损近 $5 亿）。联合创始人 CEO Andrew Feldman 持股价值近 $19 亿，CTO Sean Lie 持股约 $10 亿。
🌍 影响范围
客户包括 OpenAI、G42、沙特 AI 大学和 AWS。Cerebras 定位为推理芯片主要供应商，直接挑战 Nvidia 的垄断地位。
🔮 后续动作
一年前因 CFIUS 审查（阿布扎比 G42 投资）IPO 搁浅，今年 4 月财务数据翻倍后重启上市。股价盘后仍在上涨。
💡 解读分析
Cerebras 的上市标志着 AI 芯片赛道进入「多极化」时代——Nvidia 不再一家独大。其 WSE 巨芯架构专为 AI 设计，在推理场景下相比 GPU 有独特优势。$660 亿估值反映市场对 AI 基础设施层的持续看好，但也要警惕营收过度集中（少数客户贡献绝大部分收入）的风险。

🏆 OpenAI Codex 正式登陆 ChatGPT 手机 App，全计划可用
📅 发布日期：2026-05-14 📰 TechCrunch / The Verge HOT
📌 核心事件
OpenAI 宣布 Codex 编程代理已集成至 ChatGPT 手机 App（iOS/Android），用户可通过手机远程管理 Codex 桌面端的所有开发任务。Preview 阶段面向所有计划开放，包括免费版和 Go 计划。
📊 关键数据
功能涵盖：跨线程工作、审查输出、审批命令、切换模型、启动新任务。文件、凭证、权限均保留在本地机器，更新通过截图、终端输出、diff 等实时回传手机。
🌍 影响范围
这是继 4 月 Codex 获得 macOS 桌面后台运行能力和 Chrome 扩展后的又一重大更新。Anthropic 2 月已推出 Claude Code 远程控制功能，双方代理编程工具竞争白热化。
🔮 后续动作
OpenAI 近期裁撤 Sora 视频生成、削减"副业项目"，全面聚焦企业市场和 Codex 代理工具。与 Anthropic 在代理编码赛道的争夺将决定谁占领开发者心智。
💡 解读分析
Codex 移动端将"随时编程"变为现实，降低了代理编程工具的门槛。免费版也开放 preview 是一个聪明的增长策略——先培养用户习惯再转化付费。但从 Anthropic 的领先优势看，OpenAI 在代理编程领域仍是追赶者。

🏆 Musk v. Altman 庭审结案陈词：一场闹剧中的真相与偏见
📅 发布日期：2026-05-14 📰 TechCrunch / The Verge BREAKING
📌 核心事件
Elon Musk 起诉 Sam Altman 一案进入结案陈词阶段。OpenAI 辩护律师 William Savitt 指出 Musk 有"选择性失忆"，声称在"风大的山顶上听到了别人听不到的话"。Musk 当天不在法庭（正随特朗普总统访问北京），Altman 和 Brockman 均出庭。
📊 关键数据
辩方指出证人使用"我不记得"达 150-200 次，论证 Musk 起诉已超过诉讼时效。Musk 曾向 Ilya Sutskever 和 Greg Brockman 捐赠 Tesla，被辩方暗示为"变相贿赂"以换取 62.5% 利润公司股份的支持。

🔮 后续动作
陪审团正在审议中。无论结果如何，此案已永久改变了 AI 行业的信任格局和合作模式。
💡 解读分析

田渊栋八人天团「Recursive Superintelligence」融资 $6.5 亿，杀入递归自我进化赛道
📅 发布日期：2026-05-14 📰 36氪 / 新智元 ✅ 已验证
📌 核心事件
成立不到半年的 Recursive Superintelligence 正式走出隐身模式，由 GV（Google Ventures）和 Greycroft 领投，AMD Ventures 和英伟达跟投，融资 $6.5 亿（约 44 亿人民币），估值 $46.5 亿。公司仅有 25 人，无产品。
📊 关键数据
八位联合创始人均为 AI 领域顶级研究员：Richard Socher（NLP 词向量奠基人）、Caiming Xiong（Salesforce AI Research 前 SVP）、田渊栋（Meta FAIR 前研究总监）、Alexey Dosovitskiy（ViT 第一作者）、Jeff Clune（达尔文·哥德尔机作者）、Tim Rocktäschel（DeepMind Genie 核心）、Josh Tobin（OpenAI 机器人团队搭建者）、Tim Shi（OpenAI 早期成员、Cresta 联创）。
🌍 影响范围
目标是实现"递归自我进化"（RSI）：让 AI 自己训练自己，自动化数据筛选、训练设计、后训练对齐、研究方向选择整条 pipeline。如果成功，将形成"AI 改进自己 → 更强的 AI 更擅长改进自己"的加速反馈循环。
🔮 后续动作
Richard Socher 宣称这是"神经网络的第三阶段，也许是最后一个阶段"——第一阶段特征工程师失业，第二阶段细分赛道公司消失，第三阶段 AI 学会训练自己。
💡 解读分析
这份创始名单几乎是过去十年 AI 关键突破的作者索引。Recursive 赌的是"AI 研究员"这个职业会消失——而这些人正是该职业的巅峰代表。$6.5 亿投给 25 人且无产品的公司，说明资本对 RSI 赛道的狂热程度。但也需警惕：递归自我进化目前更多是概念而非已验证的技术路径。

微软开始取消 Claude Code 许可，全面转向 GitHub Copilot CLI
📅 发布日期：2026-05-14 📰 The Verge ✅ 已验证
📌 核心事件
微软 Experiences + Devices 团队（Windows、M365、Outlook、Teams、Surface）计划在 6 月 30 日前全面停用 Claude Code，迁移到 GitHub Copilot CLI。数千名微软开发者将受影响。
📊 关键数据
微软去年 12 月向数千名开发者开放 Claude Code，包括无编程经验的设计师和项目经理。但 Claude Code 在内部"太受欢迎"，反而削弱了微软自研的 Copilot CLI。6/30 是微软当前财年最后一天，取消许可可直接削减运营支出。
🌍 影响范围
微软曾是 Anthropic 最大的客户之一。EVP Rajesh Jha 表示 Claude Code 是"学习过程的重要部分"，但 Copilot CLI 能让微软直接塑造产品以适应自身代码库和工作流。
🔮 后续动作
Copilot CLI 仍可使用 Anthropic 模型和 OpenAI 模型。微软此前考虑收购 Cursor 来弥补 Copilot 差距，但出于监管考量转向其他 AI 初创公司投资。
💡 解读分析
这是一个标志性事件：即使是最亲密的合作伙伴，当自家产品被"碾压"时也会选择退出。微软内部开发者用脚投票选 Claude Code，但现在用行政手段强制迁移到 Copilot CLI。这既反映了 AI 编程工具竞争的激烈程度，也暴露了大厂"自研 vs 采购"的永恒矛盾。

Notion 发布 AI Agent 开发者平台：Workspace 变身 Agent 协作中枢
📅 发布日期：2026-05-13 📰 TechCrunch NEW
📌 核心事件
Notion 发布开发者平台，将工作空间升级为 AI Agent 协作中枢。新功能包括：Workers（云端代码运行沙箱）、数据库同步（支持任何 API 数据源）、外部 Agent 直接对话（Claude Code、Cursor、Codex、Decagon 已支持）。
📊 关键数据
自 2 月推出 Custom Agents 以来，Notion 用户已构建超过 100 万个自定义 Agent。Workers 功能在 8 月前免费。外部 Agent API 允许企业连接自建内部 Agent。
🌍 影响范围
Notion 正从"笔记工具+AI 功能"转型为 Agent 编排层——协调跨工具、跨数据源的 AI 工作。CEO Ivan Zhao 承认"Notion 历史上不是最开发者友好的平台，但情况正在改变"。
🔮 后续动作
Notion CLI 已上线，开发者可通过 MCP（Model Context Protocol）连接外部服务，也可通过 Workers 编写自定义逻辑处理 MCP 无法满足的场景。
💡 解读分析
Notion 的战略转型代表了 SaaS 平台的一个新范式：不再自己造轮子，而是成为 Agent 生态的"操作系统"。100 万 Custom Agents 的数据说明需求旺盛，但 Notion 面临来自传统开发平台和新兴 Agent 编排工具的双重竞争。

Google DeepMind 实验性「AI-enabled pointer」：下一代交互是「指哪 AI 打哪」
📅 发布日期：2026-05-15 📰 36氪 / 新智元 NEW
📌 核心事件
Google DeepMind 发布实验原型「AI-enabled pointer」，在键盘、鼠标、触屏之后探索下一代人机交互范式。Hassabis 盛赞该项目，称其将"指哪 AI 打哪，连提示词都省了"。
📊 关键数据
原型演示显示用户可以通过简单的指向动作触发 AI 理解意图并执行操作，无需输入完整提示词。
🌍 影响范围
如果成熟，这种交互方式可能颠覆现有的提示工程范式，让 AI 交互回归直觉化。
🔮 后续动作
目前仍为实验原型，距离产品化还有距离。但方向明确：AI 理解上下文的能力越强，用户输入的门槛就越低。
💡 解读分析
这是 DeepMind 对"AI 交互终极形态"的一次探索。从命令行到 GUI、从触屏到语音、从语音到 Agent、从 Agent 到 Pointer——交互的历史就是一条不断降低用户认知负担的曲线。Pointer 如果能成熟落地，将是提示工程的终结者。

Anthropic 新政：抛弃最忠实的 Agent 用户，引发争议
📅 发布日期：2026-05-15 📰 36氪 / 新智元 争议
📌 核心事件
Anthropic 推出新的使用政策，对 Agent/自动化用户进行限制，被批评为"过河拆桥"——最忠实的 Agent 用户反成被打击对象。
📊 关键数据

💡 解读分析
Anthropic 的困境在于：Agent 用户带来了巨大的 API 消耗量，但也带来了滥用风险和不可控的模型行为。限制 Agent 可能是为了控制风险，但代价是疏远了最具技术深度的用户群体。长期来看，这可能将用户推向 OpenAI Codex 或开源方案。
